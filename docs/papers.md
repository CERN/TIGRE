# Papers using TIGRE

Research that uses TIGRE for its reconstructions or simulations, across
medical, particle, industrial and scientific imaging. Papers about TIGRE
itself are on the [Citing TIGRE](citing.md) page.

```{include} _generated/papers.md
```

## How this list is built

Most entries come from the papers that cite TIGRE. A citation alone does not
mean a paper used TIGRE, so we only list a paper when the text around the TIGRE
citation says it was used (for example, "projections were simulated with
TIGRE"), or when a TIGRE maintainer checked the paper. Papers that only mention TIGRE among other
toolboxes are left out.

The list is not complete: papers whose citing sentence is not available, and
work that uses TIGRE without citing it (for example through CIL's TIGRE
backend), are still missing.

## Add your paper

If you have published work that uses TIGRE:

- add its DOI or arXiv number and an area to
  [`docs/papers.yaml`](https://github.com/CERN/TIGRE/blob/master/docs/papers.yaml)
  and open a pull request (the title, authors and venue are filled in
  automatically), or
- post the reference in
  [GitHub Discussions](https://github.com/CERN/TIGRE/discussions) and we will
  add it.
